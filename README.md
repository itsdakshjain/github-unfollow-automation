# GitHub Non-Follower Cleaner

A simple, safe, and efficient way to clean up your GitHub "Following" list using the browser developer console.

## 🚀 Usage
1. Navigate to your **Following** tab on GitHub.
2. Press `F12` (or `Cmd+Option+I`) to open the Developer Tools.
3. Copy the code from `unfollow.js` in this repository.
4. Paste it into the **Console** and hit Enter.

## 🛡️ Safety Features
- **Batching:** Processes users in small groups to avoid account flags.
- **Human-like Delay:** Includes randomized pauses (3-5s) between actions.
- **Privacy:** No Personal Access Tokens (PAT) required.
